# Language Center Management System

A full-stack management platform for language centers, designed to support secure account access, administrative workflows, reporting, multi-tenant operations, and coordinated frontend-backend experiences.

> **Project status:** In Development  
> **My role:** Team Leader / Full-Stack Developer

## Overview

The Language Center Management System is a multi-module application built to support the operational and administrative needs of a language center.

The system combines a Laravel backend with React and Inertia.js on the frontend, alongside Filament-based administrative interfaces.

My work includes team coordination, backend development, selected frontend implementation, authentication and account-security workflows, reporting, and integration between application modules.

## Core Capabilities

- Secure authentication and account access
- Account lockout and password-security workflows
- Administrative dashboards and management interfaces
- Multi-tenant and center-aware workflows
- Structured reporting and export functionality
- React and Inertia.js frontend integration
- Filament-based administrative workflows
- Automated testing for critical application behavior
